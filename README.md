## Rotativa o sticky: la decisión que casi nadie explica

Dentro de la misma cuenta puedes elegir entre dos comportamientos de sesión, y saber cuál necesitas te ahorra dinero porque evita repetir peticiones.

**Sesiones rotativas**: cada solicitud sale por una IP distinta. Sirven para trabajo masivo y sin estado: recopilar listados, recorrer catálogos, hacer scraping de resultados de búsqueda. Repartir la carga entre muchos IPs reduce la probabilidad de chocar con límites de velocidad. Se conectan por la puerta 823 en HTTP/HTTPS y la 824 en SOCKS5.

**Sesiones sticky**: la misma IP se mantiene durante un periodo, entre 1 y 120 minutos, con 30 minutos por defecto. Son las que necesitas para procesos con estado: iniciar sesión, añadir productos a un carrito, rellenar formularios de varios pasos o gestionar varias cuentas con una IP estable cada una. Se asignan a puertas de la franja 10000–20000.

En la práctica, el parámetro de sesión del nombre de usuario decide cuál de las dos usas. Si quieres el mismo IP, repites el mismo identificador de sesión; si quieres rotación, lo omites. No hay que cambiar ni el host ni el puerto.
